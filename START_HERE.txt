    EEG Viewer - 多通道腦波可視化工具 (Windows 桌面版)
================================================================

📦 快速開始（3 步驟）

1. 安裝依賴
   ─────────────────────────────────────────────────
   在此資料夾開啟 PowerShell 或命令提示字元，執行：

   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

   或者直接雙擊：install.bat（如果有建立）

2. 測試安裝
   ─────────────────────────────────────────────────
   python test_installation.py

   應該看到 "所有測試通過！"

3. 啟動程式
   ─────────────────────────────────────────────────
   python main.py

   或者直接雙擊：run.bat

================================================================

📁 資料集結構範例

您的 EEG 資料應該組織成以下結構之一：

方式 A - 階層式（推薦）：
   D:\EEG_Data\
   ├── subject01\
   │   ├── recording01.edf
   │   ├── recording02.edf
   │   └── annotations.csv      ← 可選
   ├── subject02\
   │   └── ...
   └── ...

方式 B - 扁平式：
   D:\EEG_Data\
   ├── file01.edf
   ├── file02.edf
   └── ...

================================================================

🎯 主要功能

✓ 支援格式：EDF, BDF, FIF, SET, VHDR
✓ 階層式瀏覽：資料集 → 受試者 → 錄音
✓ 多通道顯示：同時查看所有通道
✓ 靈活適應：
  - 不同受試者可以有不同通道數
  - 不同檔案可以有不同通道名稱
  - 自動適應不同採樣率
✓ 標註支援：自動載入癲癇發作等事件標記
✓ 互動控制：縮放、平移、時間導航

❓ 常見問題

Q: 安裝 pip 套件失敗？
A: 確保已安裝 Python 3.9+
   升級 pip：python -m pip install --upgrade pip

Q: 看到警告 "Channel names are not unique"？
A: 這是正常的！程式已自動處理，不影響功能。

Q: 不同檔案的通道數不一樣？
A: 完全支援！程式會自動適應。

Q: 記憶體不足？
A: 減少「顯示時間」（例如從 30 秒降到 10 秒）
   減少同時顯示的通道數
